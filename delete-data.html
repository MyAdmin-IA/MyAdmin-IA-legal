🔒 Droit à l'effacement (Art. 17 RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous avez le droit de demander l'effacement de vos données personnelles dans certaines conditions, également appelé "droit à l'oubli".

📋 Types de Données que Vous Pouvez Supprimer

Vous pouvez demander la suppression totale ou partielle de vos données :

📄 Documents et Fichiers

Tous vos documents uploadés, scannés ou reçus par e-mail.

💬 Historique de Conversation IA

Toutes vos conversations avec l'assistant MyAdmin IA.

📊 Analyses et Résultats

Toutes les analyses de documents effectuées par l'IA.

📝 Notes et Rappels

Toutes vos notes personnelles et rappels créés dans l'application.

👤 Données de Profil

Vos informations personnelles (nom, prénom, photo de profil).

📧 Données d'E-mails

E-mails reçus via votre adresse unique MyAdmin IA.

🔄 Suppression Complète vs Suppression Partielle

Option 1 : Suppression Totale (sans supprimer le compte)

Supprime TOUTES vos données tout en conservant votre compte actif. Vous pourrez continuer à utiliser MyAdmin IA avec un compte "vierge".

Option 2 : Suppression Partielle

Supprime uniquement certaines catégories de données que vous spécifiez (ex : uniquement les documents, uniquement l'historique IA, etc.).

📱 Suppression depuis l'Application

La méthode la plus simple pour supprimer vos données spécifiques :

Pour supprimer des documents individuels :

  • Ouvrez l'application MyAdmin IA
  • Allez dans Documents (onglet en bas)
  • Faites glisser un document vers la gauche ou appuyez longuement
  • Sélectionnez "Supprimer"

Pour supprimer l'historique de conversation :

  • Ouvrez l'application MyAdmin IA
  • Allez dans Chat IA
  • Appuyez sur l'icône Rafraîchir pour réinitialiser la conversation

Pour une suppression complète par e-mail :

Contactez-nous directement (voir section ci-dessous).

📧 Demande par E-mail

Pour une suppression totale ou partielle de vos données, vous pouvez nous contacter par e-mail :

Envoyez un e-mail à :

✉️ Demander la suppression de mes données

E-mail : contact@mail.myadminia.com

Informations à fournir dans votre e-mail :

  • Objet : Demande de suppression de données (RGPD)
  • Adresse e-mail : Celle associée à votre compte MyAdmin IA
  • Type de suppression : Totale ou partielle (précisez les catégories)
  • Pièce jointe (si nécessaire) : Pièce d'identité pour vérification

⏱️ Délai de Traitement

  • Suppression depuis l'app : Immédiate
  • Suppression par e-mail : Sous 72 heures ouvrées maximum
  • Effacement complet des serveurs : Sous 30 jours maximum (conformément au RGPD)

📋 Exceptions au Droit à l'Effacement (Art. 17.3 RGPD)

Certaines données peuvent être conservées si nous avons une obligation légale :

  • Données de facturation : 10 ans (obligation comptable française)
  • Logs de connexion : 12 mois maximum (obligation de sécurité)

Ces données sont anonymisées autant que possible et ne sont accessibles qu'en cas de contrôle légal.

🔐 Autres Droits RGPD Disponibles

En plus du droit à l'effacement, vous disposez également de :

  • Droit d'accès : Obtenir une copie de toutes vos données personnelles
  • Droit de rectification : Corriger vos données inexactes
  • Droit à la portabilité : Recevoir vos données dans un format lisible (JSON, CSV)
  • Droit d'opposition : Vous opposer au traitement de vos données
  • Droit à la limitation : Suspendre temporairement le traitement de vos données

Pour exercer ces droits, contactez-nous à : contact@mail.myadminia.com

❓ Questions Fréquentes

Q : La suppression de mes données est-elle immédiate ?

R : La suppression est effective immédiatement dans l'application, mais l'effacement complet de nos serveurs et sauvegardes peut prendre jusqu'à 30 jours conformément au RGPD.

Q : Puis-je récupérer mes données après suppression ?

R : Non, la suppression est définitive et irréversible. Nous vous recommandons d'exporter vos données importantes avant toute suppression.

Q : Mon compte sera-t-il supprimé si je supprime toutes mes données ?

R : Non, votre compte restera actif. Seules vos données seront effacées. Si vous souhaitez également supprimer votre compte, consultez notre page de suppression de compte.

Q : Puis-je supprimer uniquement certaines analyses tout en conservant mes documents ?

R : Oui, vous pouvez demander une suppression partielle en précisant exactement quelles données vous souhaitez effacer.

Q : Mes données de facturation seront-elles supprimées ?

R : Non, conformément aux obligations légales françaises, les données de facturation doivent être conservées pendant 10 ans. Ces données sont cependant anonymisées autant que possible.
